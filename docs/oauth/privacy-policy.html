Política de privacidade

Última atualização: 17 de agosto de 2026.

Esta política descreve como a aplicação "Documentário Diário" (ver página inicial) acessa e usa dados de conta do Google, exigido pela verificação de aplicações OAuth do Google. A aplicação é de uso pessoal único, operada e usada exclusivamente pelo desenvolvedor, para automatizar a publicação de vídeos no próprio canal do YouTube. Não há outros usuários e nenhum dado é coletado de terceiros.

Dados acessados

A aplicação solicita dois escopos de acesso da API do YouTube, via OAuth 2.0:

  • https://www.googleapis.com/auth/youtube.upload — permite enviar vídeos ao canal do YouTube do operador;
  • https://www.googleapis.com/auth/youtube.readonly — permite ler metadados básicos do canal (nome, identificador, configuração de privacidade padrão), usado apenas para confirmar que o canal autenticado é o correto antes de qualquer publicação.

A aplicação não lê, armazena nem processa nenhum outro dado da Conta Google do operador (e-mail, contatos, Drive, agenda, ou qualquer outro produto Google além da API do YouTube listada acima).

Como os dados são usados

O único uso dos dados de acesso é automatizar o envio de vídeos ao canal do próprio operador, num horário diário fixo, sem intervenção humana a cada publicação. O token de atualização (refresh token) obtido no consentimento OAuth é usado exclusivamente por esse processo automatizado.

Compartilhamento de dados

Nenhum dado de conta do Google é compartilhado, vendido, transferido ou disponibilizado a terceiros, sob nenhuma circunstância. A aplicação não tem outros usuários além do próprio operador e não expõe nenhuma interface pública que exponha esses dados.

Armazenamento e proteção

As credenciais OAuth (client ID, client secret e refresh token) são armazenadas como segredos criptografados na infraestrutura de produção (Cloudflare Workers Secrets), nunca em texto plano, nunca em controle de versão e nunca registradas em log. Apenas o processo automatizado do próprio operador tem acesso a esses segredos.

Retenção e revogação

O token de atualização é mantido até ser revogado pelo operador ou substituído por um novo consentimento. O operador (e, por ser uso pessoal, o próprio titular da conta) pode revogar o acesso a qualquer momento em myaccount.google.com/permissions, o que invalida o token imediatamente.
