Documentário Diário — automação de publicação no YouTube

Esta é a página de apresentação de uma aplicação de uso pessoal e uso único: um pipeline automatizado, operado por um único desenvolvedor para o próprio canal do YouTube (@hunt27lab, "Hunt"), que gera e publica um vídeo documentário narrado por dia.

A aplicação roda inteiramente em infraestrutura própria (Cloudflare Workers) e não é distribuída, vendida ou oferecida a terceiros. Não existe cadastro de usuários, painel público ou qualquer interação de terceiros com a aplicação — ela existe apenas para automatizar a publicação de vídeos do próprio operador.

O que a aplicação faz

  • Gera roteiro, narração, legendas e vídeo de forma automatizada;
  • Envia o vídeo pronto para o canal do YouTube do próprio operador, via API oficial do YouTube (upload resumível), usando o escopo youtube.upload;
  • Confirma qual canal está autenticado antes de publicar, usando o escopo youtube.readonly (somente leitura de metadados básicos do canal).
